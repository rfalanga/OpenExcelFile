# Details of this project

This project is my first attempt at creating a workbook-style application using C#. It required the use of ActiveX controls to embed Excel-like functionality within a Windows Forms application. The main features of the application include:

- Displaying the "Sample Excel Spreadhseet.xlsx" file within the application.

Because it relies on ActiveX controls, the application is limited to Windows OS. The project was developed using Visual Studio 2022 and C#. And ActiveX controls are a security risk, so I don't like this approach.

I was following [this tutorial](https://learn.microsoft.com/en-us/visualstudio/vsto/how-to-programmatically-open-workbooks?view=vs-2022&tabs=csharp).
